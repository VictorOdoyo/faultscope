# RMS phasor conventions

The time convention is exp(j omega t), ABC positive sequence. Sequence order is zero, positive, negative. The phase transform rows are `[1,1,1]`, `[1,a²,a]`, `[1,a,a²]` for a=exp(j120°). Currents enter a fault from the network. Branch end currents enter the branch from each end. RMS ampere conversion uses Sbase/(sqrt(3) VLLbase); transformer terminals at different voltage levels therefore have different ampere bases. No instantaneous waveform or DC component is embedded in the complex RMS phasors.
