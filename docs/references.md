# Engineering references

- [SEL, Application Guidelines for Ground Fault Protection](https://cdn.selinc.com/assets/Literature/Publications/Technical%20Papers/6065_ApplicationGuidelines_Web.pdf): sequence-network connections and common-ground fault context.
- [ABB, Electrical Devices technical handbook](https://library.e.abb.com/public/561a28a17753c444c125714f00360967/1SDC010001D0204.pdf): equivalent R/X peak-current expression used in the explicitly limited screen.

The standard context for screening is IEC 60909-0:2016, but the repository does not implement all that standard's correction factors or methods and makes no compliance claim.

Implementation and synthetic examples are original. Sources establish equation conventions; they do not endorse this software.
