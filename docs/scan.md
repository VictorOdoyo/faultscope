# Bus fault scans

Scan chooses up to 50 buses and one to four fault types. Each row reports phase RMS and residual current or an explicit model/source error. The scan uses classical 1 pu source/reference voltages by default and does not silently substitute equipment screening factors. To compare equipment or use a custom prefault reference, run the corresponding explicit study action. Unrelated unsourced islands do not invalidate a sourced bus study.
