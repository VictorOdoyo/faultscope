# Local engineering workbench

The browser presents a study library, selectable fault-bus diagram and sequence equivalents, structured model inspector, advanced JSON editor, numerical result tables and a full-precision record. Model changes validate before applying and invalidate prior result exports. Undo keeps 30 model snapshots. Export model JSON separately from result JSON; the result contains the exact model and engine provenance. Browser drafts stay in local storage and can be removed by clearing site data.

Fault bus/type controls populate the visible options JSON; scan and screening actions explicitly change the applicable controls. Fault-current phasors and source/branch contribution tables accompany each study.

Print uses the browser PDF/print renderer. The local server is not a hosting deployment. Reports retain failed coordination and model applicability limits; visual overlap alone does not imply a pass.
